# 08강. 배열

## 학습 목표

- 여러 값을 하나의 목록으로 저장합니다.
- 배열의 인덱스를 이해합니다.
- 배열에 값을 추가하고 읽습니다.

## 쉬운 설명

배열은 여러 개의 값을 순서대로 담는 목록입니다.

```js
const fruits = ["사과", "바나나", "딸기"];
```

배열의 순서는 0부터 시작합니다.

```js
console.log(fruits[0]); // 사과
console.log(fruits[1]); // 바나나
```

## 배열 길이

```js
console.log(fruits.length);
```

## 값 추가하기

```js
fruits.push("포도");
console.log(fruits);
```

`const` 배열이어도 배열 안의 값은 추가할 수 있습니다. 단, 배열 자체를 다른 배열로 바꾸는 것은 안 됩니다.

## 예제 코드

예제 파일:

```txt
08-배열/examples/arrays.html
```

## 실행 방법

1. `arrays.html`을 엽니다.
2. 화면에 표시되는 목록을 확인합니다.
3. 배열에 값을 추가해 봅니다.

## 자주 하는 실수

- 첫 번째 값의 인덱스를 1이라고 생각함
- 없는 인덱스를 읽어서 `undefined`가 나옴
- 배열과 문자열을 헷갈림

## 연습문제

1. 좋아하는 음식 3개를 배열로 만드세요.
2. 첫 번째 음식을 출력하세요.
3. 새 음식을 하나 추가하세요.
4. 배열 길이를 출력하세요.

## 정답 예시

```js
const foods = ["김밥", "라면", "떡볶이"];
console.log(foods[0]);
foods.push("피자");
console.log(foods.length);
```

## 요약

- 배열은 여러 값을 순서대로 저장합니다.
- 인덱스는 0부터 시작합니다.
- `push()`로 값을 추가할 수 있습니다.
