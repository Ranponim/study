# 19강. npm 맛보기

## 학습 목표

- npm이 무엇인지 이해합니다.
- 패키지라는 개념을 배웁니다.
- 지금까지의 브라우저 예제와 npm의 차이를 구분합니다.

## 쉬운 설명

npm은 JavaScript 도구와 라이브러리를 설치하는 공간이자 명령어입니다. 다른 사람이 만들어 둔 코드를 패키지라고 부르고, npm으로 설치해서 사용할 수 있습니다.

지금까지 강의는 `.html` 파일을 더블클릭해서 실행했습니다. npm은 보통 Node.js 설치가 필요하고, 터미널 명령어를 사용합니다.

## npm이 필요한 경우

- React 같은 프레임워크를 사용할 때
- 코드 포맷터나 테스트 도구를 사용할 때
- 외부 라이브러리를 설치할 때
- 여러 파일을 묶어 배포할 때

## 기본 명령어 맛보기

아래 명령은 지금 바로 실행하지 않아도 됩니다. 모양만 익혀 두세요.

```bash
npm init -y
npm install 라이브러리이름
npm run dev
```

## package.json

npm 프로젝트에는 보통 `package.json` 파일이 있습니다. 프로젝트 이름, 명령어, 설치한 패키지 정보가 들어갑니다.

예:

```json
{
  "name": "my-project",
  "scripts": {
    "start": "node index.js"
  }
}
```

## 실행 방법

1. `npm-concept.html`을 엽니다.
2. npm이 어떤 역할을 하는지 그림처럼 이해합니다.
3. 실제 설치는 다음 단계 학습에서 진행해도 됩니다.

## 자주 하는 실수

- npm을 JavaScript 문법이라고 생각함
- `node_modules` 폴더를 GitHub에 올림
- 패키지를 많이 설치할수록 좋다고 생각함

## 연습문제

1. npm이 필요한 상황을 2개 적어 보세요.
2. `package.json`의 역할을 한 문장으로 설명해 보세요.
3. `node_modules`를 GitHub에 올리지 않는 이유를 생각해 보세요.

## 정답 예시

- npm은 JavaScript 패키지를 설치하고 실행 명령을 관리하는 도구입니다.
- `package.json`은 프로젝트 정보와 명령어, 의존성을 기록합니다.
- `node_modules`는 크고 다시 설치할 수 있으므로 GitHub에 올리지 않습니다.

## 요약

- npm은 JavaScript 생태계의 패키지 관리자입니다.
- 초반 강의에서는 npm 없이도 충분히 배울 수 있습니다.
- React나 빌드 도구를 배울 때 npm이 중요해집니다.
