# JavaScript 입문 강의

코딩이 처음인 사람을 위한 JavaScript 학습 저장소입니다.  
이 저장소는 **브라우저에서 바로 실행해 보면서 배우는 방식**으로 구성되어 있습니다.

## 이 저장소의 목표

- 프로그래밍이 처음이어도 JavaScript의 기본 문법을 이해한다.
- HTML 파일을 더블클릭해서 예제를 직접 실행한다.
- 작은 예제를 반복해서 작성하며 웹 페이지를 조작하는 감각을 익힌다.
- 마지막에는 간단한 미니 프로젝트를 직접 만들어 본다.

## 준비물

1. Chrome 또는 Edge 같은 웹 브라우저
2. Visual Studio Code
3. GitHub 계정
4. 처음에는 Node.js 설치가 없어도 됩니다. `19-npm맛보기`에서 처음 다룹니다.

## 학습 방법

각 강의 폴더에 들어가면 `README.md`가 있습니다. GitHub에서는 폴더를 클릭하면 강의 문서가 바로 보입니다.

각 강의는 다음 순서로 읽으면 됩니다.

1. 학습 목표 확인
2. 쉬운 설명 읽기
3. `examples` 폴더의 예제 실행
4. 직접 코드 수정해 보기
5. 연습문제 풀기
6. 정답 예시와 비교하기

## 예제 실행 방법

대부분의 예제는 다음 방식으로 실행합니다.

1. 강의 폴더로 이동합니다.
2. `examples` 폴더를 엽니다.
3. `.html` 파일을 더블클릭합니다.
4. 브라우저에서 결과를 확인합니다.
5. 코드 설명에 따라 파일을 수정해 봅니다.

## GitHub에 올리는 방법

아직 Git을 잘 몰라도 아래 명령은 나중에 그대로 따라 하면 됩니다.

```bash
git init
git add .
git commit -m "add javascript beginner course"
git branch -M main
git remote add origin <내 GitHub 저장소 주소>
git push -u origin main
```

`<내 GitHub 저장소 주소>` 부분은 GitHub에서 새 저장소를 만든 뒤 보이는 주소로 바꾸면 됩니다.
