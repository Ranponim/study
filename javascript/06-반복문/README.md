# 06강. 반복문

## 학습 목표

- 같은 작업을 여러 번 반복합니다.
- `for`문과 `while`문을 이해합니다.
- 반복문에서 인덱스를 사용합니다.

## 쉬운 설명

반복문은 같은 코드를 여러 번 실행할 때 사용합니다. 예를 들어 “안녕하세요”를 5번 출력하고 싶을 때 같은 줄을 5번 쓰지 않아도 됩니다.

```js
for (let i = 1; i <= 5; i++) {
  console.log(i + "번째 안녕하세요");
}
```

## for문 구조

```js
for (시작; 조건; 변화) {
  반복할 코드
}
```

예:

```js
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

## while문

```js
let count = 1;

while (count <= 3) {
  console.log(count);
  count = count + 1;
}
```

3. 콘솔 출력 개수를 확인합니다.

## 자주 하는 실수

- 반복 조건이 끝나지 않아 무한 반복이 됨
- `i++`를 빼먹음
- `i <= 5`와 `i < 5`의 차이를 헷갈림

## 연습문제

1. 1부터 10까지 출력하세요.
2. 1부터 10까지의 합계를 구하세요.
3. 2단 구구단을 출력하세요.

## 정답 예시

```js
let total = 0;

for (let i = 1; i <= 10; i++) {
  total = total + i;
}

console.log(total);
```

## 요약

- 반복문은 같은 일을 여러 번 할 때 사용합니다.
- `for`문은 반복 횟수가 정해져 있을 때 자주 사용합니다.
- `while`문은 조건이 중요할 때 사용합니다.
