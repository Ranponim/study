# 미니 프로젝트 01. 카운터

## 목표

버튼을 클릭하면 숫자가 증가하거나 감소하는 간단한 카운터를 만듭니다.

## 사용하는 개념

- 변수
- DOM 선택
- 이벤트
- 함수

## 파일

```txt
20-미니프로젝트/01-카운터/index.html
```

## 실행 방법

`index.html` 파일을 더블클릭합니다.

## 기능

- 현재 숫자 표시
- 증가 버튼
- 감소 버튼
- 초기화 버튼

## 만드는 순서

1. 숫자를 보여 줄 요소를 만듭니다.
2. 증가/감소/초기화 버튼을 만듭니다.
3. JavaScript에서 요소를 선택합니다.
4. `count` 변수를 만듭니다.
5. 버튼 클릭 이벤트를 연결합니다.
6. 숫자가 바뀔 때마다 화면을 다시 그립니다.

## 핵심 코드

```js
let count = 0;

function render() {
  number.textContent = count;
}
```

## 자주 하는 실수

- `count` 값만 바꾸고 화면을 업데이트하지 않음
- 버튼을 잘못 선택함
- 이벤트 이름 `click`을 틀림
