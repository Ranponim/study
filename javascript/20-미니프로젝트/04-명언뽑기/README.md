# 미니 프로젝트 04. 명언뽑기

## 목표

버튼을 누르면 준비된 문장 중 하나가 랜덤으로 표시되는 명언뽑기를 만듭니다.

## 사용하는 개념

- 배열
- 객체
- 함수
- 랜덤 숫자
- DOM 변경
- 이벤트

## 파일

```txt
20-미니프로젝트/04-명언뽑기/index.html
```

## 실행 방법

`index.html` 파일을 더블클릭합니다.

## 기능

- 랜덤 명언 표시
- 작성자 표시
- 다시 뽑기 버튼

## 만드는 순서

1. 명언 객체 배열을 만듭니다.
2. 랜덤 인덱스를 구합니다.
3. 배열에서 하나를 꺼냅니다.
4. 문장과 작성자를 화면에 표시합니다.
5. 버튼 클릭 이벤트를 연결합니다.

## 핵심 코드

```js
const randomIndex = Math.floor(Math.random() * quotes.length);
const quote = quotes[randomIndex];
```

## 자주 하는 실수

- `Math.random()`이 0 이상 1 미만이라는 점을 잊음
- 배열 길이보다 큰 인덱스를 사용함
- 화면 요소는 선택했지만 값을 넣지 않음

## 확장 아이디어

1. 명언을 더 추가하세요.
2. 배경색도 랜덤으로 바꿔 보세요.
3. 이전에 나온 명언이 바로 다시 나오지 않게 해 보세요.
