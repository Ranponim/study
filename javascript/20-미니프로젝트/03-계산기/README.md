# 미니 프로젝트 03. 계산기

## 목표

두 숫자를 입력하고 더하기, 빼기, 곱하기, 나누기 결과를 표시하는 계산기를 만듭니다.

## 사용하는 개념

- 입력값 읽기
- 숫자 변환
- 조건문
- 함수
- 이벤트

## 파일

```txt
20-미니프로젝트/03-계산기/index.html
```

## 실행 방법

`index.html` 파일을 더블클릭합니다.

## 기능

- 첫 번째 숫자 입력
- 두 번째 숫자 입력
- 연산 선택
- 계산 결과 표시
- 잘못된 입력 안내

## 만드는 순서

1. 숫자 입력창 2개를 만듭니다.
2. 연산 버튼을 만듭니다.
3. 버튼 클릭 이벤트를 연결합니다.
4. `Number()`로 입력값을 숫자로 바꿉니다.
5. 연산 종류에 따라 결과를 계산합니다.
6. 결과를 화면에 표시합니다.

## 핵심 코드

```js
const a = Number(firstInput.value);
const b = Number(secondInput.value);
const result = a + b;
```

## 자주 하는 실수

- 입력값은 기본적으로 문자열이라는 점을 잊음
- `"2" + "3"`이 `"23"`이 되는 것을 보고 당황함
- 0으로 나누는 경우를 처리하지 않음
