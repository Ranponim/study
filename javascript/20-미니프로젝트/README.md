# 20강. 미니 프로젝트

## 목표

지금까지 배운 JavaScript 기초를 사용해 작은 웹 프로젝트를 만들어 봅니다. 모든 프로젝트는 별도 설치 없이 `index.html`을 더블클릭해서 실행하는 방식입니다.

## 프로젝트 목록

| 번호 | 프로젝트 | 설명 |
|---|---|---|
| 01 | [카운터](./01-카운터) | 버튼을 누르면 숫자가 증가/감소합니다. |
| 02 | [투두리스트](./02-투두리스트) | 할 일을 추가하고 삭제합니다. |
| 03 | [계산기](./03-계산기) | 두 숫자로 간단한 계산을 합니다. |
| 04 | [명언뽑기](./04-명언뽑기) | 버튼을 누르면 랜덤 문장이 표시됩니다. |

## 진행 순서

1. 먼저 완성된 `index.html`을 실행합니다.
2. 화면이 어떻게 동작하는지 관찰합니다.
3. 코드를 위에서 아래로 읽습니다.
4. 작은 기능 하나를 바꿔 봅니다.
5. README의 확장 아이디어를 하나 선택해 추가합니다.

## 프로젝트를 할 때 중요한 태도

처음부터 외우려고 하지 마세요. 프로젝트는 “기억 테스트”가 아니라 “찾아보며 조립하는 연습”입니다.

막히면 다음 순서로 확인하세요.

```txt
HTML 요소가 있는가?
→ JavaScript에서 선택했는가?
→ 이벤트가 연결되었는가?
→ 값이 바뀌는가?
→ 화면에 다시 표시했는가?
```
