# 미니 프로젝트 02. 투두리스트

## 목표

할 일을 입력하고 목록에 추가한 뒤 삭제할 수 있는 투두리스트를 만듭니다.

## 사용하는 개념

- 배열
- 객체
- DOM 조작
- 폼 입력값
- 이벤트
- localStorage 맛보기

## 파일

```txt
20-미니프로젝트/02-투두리스트/index.html
```

## 실행 방법

`index.html` 파일을 더블클릭합니다.

## 기능

- 할 일 입력
- 할 일 추가
- 완료 체크
- 삭제
- 새로고침 후에도 저장

## 만드는 순서

1. 입력창과 버튼을 만듭니다.
2. 할 일을 저장할 배열을 만듭니다.
3. 폼 제출 이벤트를 처리합니다.
4. 입력값으로 새 할 일 객체를 만듭니다.
5. 배열을 화면 목록으로 그립니다.
6. 삭제 버튼으로 항목을 제거합니다.
7. localStorage에 저장합니다.

## 핵심 코드

```js
const todos = [];

todos.push({
  id: Date.now(),
  text: input.value,
  done: false
});
```

## 자주 하는 실수

- 입력값을 추가한 뒤 입력창을 비우지 않음
- 배열은 바뀌었지만 화면을 다시 그리지 않음
- localStorage에 배열을 그대로 저장하려 함

## 확장 아이디어

1. 완료된 항목에 취소선을 표시하세요.
2. 전체 삭제 버튼을 추가하세요.
3. 남은 할 일 개수를 표시하세요.
