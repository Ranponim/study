# 00강. 환경설정

## 학습 목표

- JavaScript를 배우기 위한 기본 도구를 준비합니다.
- 브라우저에서 HTML 파일을 실행하는 방법을 익힙니다.
- GitHub에서 강의 파일을 읽는 방법을 이해합니다.

## 쉬운 설명

JavaScript는 웹 브라우저에서 실행되는 프로그래밍 언어입니다. 처음부터 복잡한 설치를 할 필요는 없습니다. 이 강의에서는 먼저 HTML 파일을 만들고, 그 안에 JavaScript를 넣어 브라우저에서 실행합니다.

필요한 것은 세 가지입니다.

1. 브라우저: Chrome 또는 Edge
2. 코드 편집기: Visual Studio Code
3. 파일을 저장할 폴더

## 예제 코드

예제 파일:

```txt
00-환경설정/examples/first-page.html
```

## 실행 방법

1. `examples` 폴더를 엽니다.
2. `first-page.html` 파일을 더블클릭합니다.
3. 브라우저가 열리면 화면의 문장을 확인합니다.
4. `F12`를 눌러 개발자 도구를 엽니다.
5. `Console` 탭에서 JavaScript 출력 결과를 확인합니다.

## 따라 해보기

`first-page.html`에서 화면에 보이는 문장을 자신의 이름이 들어간 문장으로 바꿔 보세요.

예:

```html
<h1>안녕하세요, 민수의 첫 JavaScript 페이지입니다.</h1>
```

## 자주 하는 실수

- 파일 확장자를 `.html`이 아니라 `.txt`로 저장함
- 코드를 저장하지 않고 브라우저를 새로고침함
- 브라우저 콘솔을 열지 않아서 출력 결과를 못 봄

## 연습문제

1. `h1` 태그 안의 문장을 바꿔 보세요.
2. `console.log()` 안의 문장을 바꿔 보세요.
3. 파일을 저장한 뒤 브라우저를 새로고침해 보세요.

## 정답 예시

```js
console.log("JavaScript 학습을 시작합니다!");
```

## 요약

- JavaScript는 브라우저에서 실행할 수 있습니다.
- `.html` 파일을 더블클릭하면 예제를 실행할 수 있습니다.
- `console.log()`는 개발자 도구 콘솔에 값을 출력합니다.
