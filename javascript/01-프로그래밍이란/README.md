# 01강. 프로그래밍이란

## 학습 목표

- 프로그래밍이 무엇인지 이해합니다.
- 코드가 위에서 아래로 실행된다는 것을 배웁니다.
- `console.log()`로 결과를 출력합니다.

## 쉬운 설명

프로그래밍은 컴퓨터에게 일을 시키는 명령서를 쓰는 일입니다. 컴퓨터는 사람처럼 눈치껏 이해하지 못하므로, 아주 정확한 순서로 명령해야 합니다.

JavaScript 코드는 보통 위에서 아래로 한 줄씩 실행됩니다.

```js
console.log("첫 번째");
console.log("두 번째");
console.log("세 번째");
```

위 코드는 첫 번째, 두 번째, 세 번째 순서로 출력됩니다.

## 예제 코드

예제 파일:

```txt
01-프로그래밍이란/examples/hello.html
```

## 실행 방법

1. `hello.html` 파일을 더블클릭합니다.
2. 브라우저에서 화면을 확인합니다.
3. `F12`를 누르고 `Console` 탭을 엽니다.
4. 출력된 문장을 확인합니다.

## 따라 해보기

`console.log()`를 하나 더 추가해 보세요.

```js
console.log("나는 JavaScript를 배우고 있습니다.");
```

## 자주 하는 실수

- 따옴표를 닫지 않음
- 괄호 `)`를 빼먹음
- 세미콜론을 꼭 써야 한다고 생각함. JavaScript에서는 대부분 없어도 되지만, 초반에는 붙이는 습관이 좋습니다.

## 연습문제

1. 자신의 이름을 콘솔에 출력해 보세요.
2. 좋아하는 음식을 콘솔에 출력해 보세요.
3. `console.log()` 세 줄을 작성하고 출력 순서를 확인해 보세요.

## 정답 예시

```js
console.log("제 이름은 지수입니다.");
console.log("좋아하는 음식은 김치찌개입니다.");
console.log("JavaScript 첫 수업입니다.");
```

## 요약

- 프로그래밍은 컴퓨터에게 명령을 내리는 일입니다.
- JavaScript는 위에서 아래로 실행됩니다.
- `console.log()`는 확인용 출력에 자주 사용합니다.
