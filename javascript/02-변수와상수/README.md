# 02강. 변수와 상수

## 학습 목표

- 값을 저장하는 방법을 배웁니다.
- `let`과 `const`의 차이를 이해합니다.
- 변수 이름을 짓는 기본 규칙을 익힙니다.

## 쉬운 설명

변수는 값을 담는 상자입니다. 예를 들어 이름, 나이, 점수 같은 값을 저장할 수 있습니다.

```js
let age = 20;
const name = "민수";
```

- `let`: 나중에 값을 바꿀 수 있습니다.
- `const`: 한 번 정하면 다시 바꿀 수 없습니다.

가능하면 기본적으로 `const`를 쓰고, 값이 바뀌어야 할 때만 `let`을 사용합니다.

## 예제 코드

예제 파일:

```txt
02-변수와상수/examples/variables.html
```

## 실행 방법

1. `variables.html`을 더블클릭합니다.
2. 브라우저 화면과 콘솔 출력을 확인합니다.
3. 변수 값을 바꾼 뒤 저장하고 새로고침합니다.

## 따라 해보기

```js
const userName = "영희";
let score = 80;
score = 95;

console.log(userName);
console.log(score);
```

## 자주 하는 실수

- `const`로 만든 값을 다시 바꾸려고 함
- 변수 이름에 띄어쓰기를 넣음
- 변수 이름을 숫자로 시작함

잘못된 예:

```js
let user name = "민수";
let 1score = 100;
```

## 연습문제

1. 자신의 이름을 `myName`이라는 상수에 저장하세요.
2. 자신의 나이를 `myAge`라는 변수에 저장하세요.
3. 나이를 1 증가시킨 뒤 출력하세요.

## 정답 예시

```js
const myName = "지수";
let myAge = 20;
myAge = myAge + 1;

console.log(myName);
console.log(myAge);
```

## 요약

- 변수는 값을 저장하는 이름표입니다.
- `let`은 변경 가능, `const`는 변경 불가능합니다.
- 변수 이름은 의미 있게 짓는 것이 좋습니다.
